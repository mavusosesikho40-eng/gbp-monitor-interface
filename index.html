Connect to your monitor repo

The monitor stores its baseline and check log in a private GitHub repo, so this page needs a GitHub token to read it. Create a fine-grained token for that one repo with Contents: read and Actions: read. Add Actions: write if you want the “Run check now” button, and Secrets: read to let the checklist confirm your secrets are set. The token is only sent to api.github.com.
